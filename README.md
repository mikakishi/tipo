# Tipografía Color con Vectores — versión corregida

Archivos listos para GitHub Pages. Sube todos estos archivos a la raíz del repositorio:

- index.html
- styles.css
- app.js
- opentype.min.js

Correcciones incluidas:

- Normalización automática de cada SVG a caja tipográfica 1000 x 1000.
- Línea base fija en y=800.
- Cajas distintas para mayúsculas, minúsculas, ascendentes y descendentes.
- Eliminación de width/height problemáticos en SVG importados.
- TTF SVG Color reconstruido para que no genere solo espacios vacíos.
- COLRv0 mantiene capas de color cuando el visor lo soporta.

Nota: Adobe suele mostrar mejor color usando “TTF SVG Color”. COLRv0 puede verse en negro en algunos programas aunque la fuente contenga color.
